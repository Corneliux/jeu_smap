SAINTE-MARIE-À-PY 3D V5 : DONNÉES LOCALES + RELIEF IGN

1. Dans le dossier, exécuter : bash installer_mode_hors_ligne.sh
   Cette commande ne nécessite Internet qu’une fois pour Three.js.
2. Installer le convertisseur raster : sudo apt install gdal-bin p7zip-full
3. Télécharger les données BD ALTI 25 m ou RGE ALTI auprès de l’IGN pour la Marne (51).
   Les décompresser dans un répertoire, par exemple ~/Téléchargements/BDALTI_51.
4. Lancer : python3 preparer_relief.py ~/Téléchargements/BDALTI_51
   Le script crée data/terrain.json. Si plusieurs fichiers couvrent la zone, il les assemble.
5. Démarrer : python3 -m http.server 8002
6. Ouvrir : http://localhost:8002
